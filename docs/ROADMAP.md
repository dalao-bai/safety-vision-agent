# 路线图

## 阶段 1：轻量 Agent MVP

- FastAPI 后端。
- SQLite 业务记忆。
- 轻量多轮 Agent 状态机。
- Vite React 验证控制台。
- 图片上传、Agent chat、结构化结果展示。

## 阶段 2：视觉工具质量

- 接入真实微调 VLM API。
- 接入真实 YOLO 安全帽/人员检测 API。
- 完善规则块检索和证据融合。
- 增强 VLM/YOLO timeout、失败降级和可观测性。

## 阶段 3：多轮专家能力

- 更细的意图分类。
- 依据追问、证据不足追问、补拍任务。
- 多专家角色协同判断。
- 历史图片、历史整改和报告检索。

## 阶段 4：复核和训练闭环

- 人工复核 UI 完善。
- 批量图片草标。
- SFT / Hard Negative / DPO 数据导出。
- accepted_records 质量校验。

## 阶段 5：生产化扩展

- 流式响应。
- 按指标决定是否重新引入队列。
- PostgreSQL 迁移。
- 向量检索历史案例。
- LangGraph 工作流升级。
- 权限、审计和部署。

当前仓库已经完成阶段 1 的主线重构，并保留阶段 4 的单样本标注反哺闭环第一版。
